# public/

Static assets for the Liberty Menopause Care website.

## Folder structure

```
public/
└── images/
    ├── hero/      # Hero section — full portrait of Dr Emma Ward
    ├── about/     # About section — Dr Emma Ward photos
    ├── clinic/    # Clinic / location photos (Hayfield)
    └── general/   # Any other images (blog, social, etc.)
```

## Image guidance

| Folder | Suggested files | Notes |
|--------|----------------|-------|
| `hero/` | `emma-hero.jpg` | Tall/portrait crop, warm neutral background |
| `about/` | `emma-about.jpg` | More relaxed/approachable than hero |
| `clinic/` | `clinic-exterior.jpg`, `clinic-interior.jpg` | The Hayfield clinic |
| `general/` | Any supplementary images | Blog headers, social cards, etc. |

Recommended formats: `.jpg` or `.webp` · Max width: 2400px · Keep files under 500 KB where possible.
